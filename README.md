# MacZip

Нативный архиватор для macOS 14 и новее на SwiftUI. Чёрный фон, белая типографика,
оранжевые акценты; светлая и системная темы доступны в настройках.

## Запуск

Готовое приложение после сборки: `build/MacZip.app`.

```sh
./Scripts/build.sh
open build/MacZip.app
```

Для сборки нужны Xcode / Command Line Tools с Swift 5.9 или новее. Внешние Swift
зависимости и Homebrew не нужны: официальный универсальный движок 7-Zip 26.05
включён в `Vendor/7zip` и копируется внутрь приложения. Сборка создаёт приложение
для архитектуры текущего Mac. Это локальная сборка с ad-hoc подписью; для публичного
распространения нужны Developer ID и нотариализация Apple.

Открыть исходники в Xcode можно через `Package.swift`. Для разработки также
доступен `swift run MacZip` из корня проекта.

## Возможности

- Открытие архивов через диалог, drag-and-drop и Finder → «Открыть с помощью».
- Просмотр папок внутри архива, хлебные крошки, поиск, сортировка, множественный
  выбор и свойства файлов. Двойной щелчок открывает папку или Quick Look.
- Предпросмотр и выборочная распаковка: извлекаются только нужные файлы.
- Создание ZIP, 7z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ и однофайлового Gzip.
- Четыре уровня сжатия для ZIP / 7z; уровни сжатия потоковых форматов учитывают
  ограничения соответствующего компрессора.
- Пароли и AES-256 при создании ZIP / 7z. В 7z можно шифровать имена файлов.
- Проверка пароля при открытии защищённого архива, включая ZIP с видимыми именами.
  Неверный пароль оставляет окно открытым для следующей попытки, без ограничения
  числа повторов. При повторном открытии и после перезапуска пароль запрашивается заново.
- Чтение RAR 4 / RAR 5, в том числе с паролем и зашифрованными именами.
- ISO, DMG, ZIPX, CAB, ARJ, LZH/LHA, CPIO, XAR, DEB, RPM, GZ, BZ2, XZ, Zstandard,
  TAR.ZST и другие форматы, поддерживаемые встроенным 7-Zip.
- Проверка целостности, отмена фоновой операции, локальная история и недавние архивы.
- Исключение `.DS_Store`, `__MACOSX` и AppleDouble `._*` при создании архива.

## Изменение содержимого

| Формат | Просмотр / распаковка | Создание | Добавить / удалить | Редактировать документ |
| --- | --- | --- | --- | --- |
| ZIP | Да | Да | Да | Да |
| 7z | Да | Да | Да | Да |
| TAR | Да | Да | Да | Да |
| TAR.GZ / TAR.BZ2 / TAR.XZ | Да | Да | Да | Да |
| GZ | Да | Один файл | — | Замена единственного файла |
| RAR | Да, включая пароли | — | — | — |
| ISO / DMG | Да | — | — | — |
| Остальные форматы | По возможностям 7-Zip | — | — | — |

В открытом ZIP / 7z / TAR кнопка **+** добавляет файлы в текущую папку. Совпадающие
имена заменяются после подтверждения. Выбранные объекты можно удалить через
контекстное меню или кнопку корзины. Исходный архив заменяется только после
успешной проверки новой версии; по умолчанию рядом остаётся резервная копия
`имя-архива.backup-XXXXXXXX`. Настройка резервных копий находится в «Настройках».

Для редактирования выберите документ и нажмите карандаш или ⌘R. Текстовые файлы
до 5 МБ открываются во встроенном редакторе. Другие поддерживаемые документы
открываются в установленном приложении macOS, например TextEdit, Pages или Word.
Сохраните и закройте документ во внешнем редакторе, затем нажмите
**«Сохранить в архив»** в MacZip. До нажатия этой кнопки архив не меняется.

Извлекается только выбранный документ, до 100 МБ. Добавление и удаление не требуют
распаковки дерева файлов. Движок может переписывать контейнер архива или повторно
сжимать solid-блоки. Для TAR со сжатием создаётся временный несжатый TAR-контейнер,
без извлечения всего дерева файлов на диск. Для операций нужно достаточно
свободного места под рабочую копию и, если включено, резервную копию.

Если документ в архиве изменился другой программой после начала редактирования,
MacZip откажется затирать более новую версию. Документ останется во временной
папке и будет доступен через меню панели редактирования → «Показать файл в Finder».

## Пароли и ограничения

- Пароли передаются 7-Zip через stdin, не включаются в аргументы процесса,
  историю или настройки. Во время работы остаются только в памяти приложения.
- При создании ZIP движок принимает печатные ASCII-символы в пароле. Для
  кириллицы и эмодзи используйте 7z; интерфейс проверяет это до сохранения.
- ZIP с AES-256 требует совместимого архиватора у получателя; встроенные
  распаковщики некоторых систем могут его не поддерживать.
- RAR и ISO доступны для чтения и извлечения. Создание и изменение RAR исключены
  из функционала; внешняя лицензия RAR не требуется.
- Многотомный архив открывается с первой части. Все части должны лежать рядом.
  Добавление и удаление в многотомных / самораспаковывающихся архивах не заявлены.
- Архивы со ссылками можно просматривать. Распаковка ссылок запрещена; обычные
  файлы в таком архиве можно выбрать и извлечь отдельно.
- При распаковке всегда создаётся отдельная папка; существующие файлы не
  перезаписываются. При создании архива также требуется свободное имя файла.
- При создании исходные файлы копируются во временную папку. После успешного
  завершения или отмены рабочие папки удаляются. Документы предпросмотра и
  редактирования очищаются при закрытии соответствующего просмотра / сеанса.
- Аварийное завершение приложения может оставить временные `MacZip-*` папки;
  они находятся в системном временном каталоге. Не удаляйте папки активной операции.
- Работа ведётся с одним открытым архивом в одном окне. Одновременно можно
  редактировать один документ. Интерфейс на русском языке.

## Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Открыть архив | ⌘O |

## Проверки

```sh
./Scripts/test.sh
```

Интеграционные тесты используют реальный движок: форматы и уровни сжатия, AES,
шифрование имён, Unicode, RAR 4/5, ISO, выборочное извлечение, изменение ZIP / 7z /
TAR / Gzip, сохранение шифрования после изменений, резервные копии, отмена,
неверный пароль, повреждённые архивы, обход путей и конфликты редактирования.
Отдельные тесты модели интерфейса проверяют многократный неверный ввод, успешную
распаковку после повторов, отмену, повторное открытие и новый экземпляр приложения.

Архитектура: `Sources/ArchiveCore` — движок и операции; `Sources/MacZip` — SwiftUI,
AppKit и Quick Look. `Scripts/build.sh debug` собирает отладочный `.app`.

Если нужно восстановить отсутствующий движок:

```sh
./Scripts/fetch-engine.sh
```

Скрипт загружает закреплённую официальную версию и проверяет SHA-256 дистрибутива.
Установить свой совместимый движок можно переменной окружения `MACZIP_7ZZ`.
